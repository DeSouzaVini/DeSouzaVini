## 💼 Projetos em Destaque (Data & Analytics)

### 🏆 FinancePlus: Sistema Analítico de Crédito e Cobrança (End-to-End)
**Descrição:** Projeto completo de Engenharia de Dados e Business Intelligence que simula a operação de uma instituição financeira especializada em crédito pessoal. O escopo cobre todas as fases de desenvolvimento, desde a modelagem relacional estruturada e geração de dados sintéticos via pipeline ETL, até a consolidação em um Dashboard Executivo de alta performance desenhado com estética *Dark/Neon Terminal*.
* **Tecnologias:** Power BI (DAX Avançado), Python (Pandas, POO, Faker), SQL Server, Figma.
* **Indicadores:** Concessão e Saldo Devedor, Inadimplência e Risco por Score, Acompanhamento de Contratos, Parcelas e Metas.
🔗 [Acesse o repositório completo](https://github.com/DeSouzaVini/FinancePlus) <br>
🔗 [Baixe o Dashboard PBIX](https://github.com/DeSouzaVini/FinancePlus/tree/main/Power%20bi)
